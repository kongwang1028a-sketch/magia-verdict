# 魔女審判模擬 — 孤島監牢

粉絲向《魔法少女的魔女審判》辯論小遊戲。使用原作角色名稱與魔法設定；劇情為粉絲向短案，非遊戲本篇。

## 章節流程

1. **序章**：艾瑪與希羅的早晨對話（長篇）  
2. **日常·兩日**：第一日／第二日共 12 場場景交談  
3. **事件**：遠野漢娜遇害，典獄長召開審判  
4. **搜索**：與希羅同行蒐證，每份證據附長對話  
5. **審判**：多輪鋪陳與異議辯論、指認魔女  

劇本為**手寫對白**（已移除灌水占位句）。容錯 3 次。本短案兇手為紫藤亞里沙。

**十三名預備魔女全員登場**（另含月代雪回憶）。右上角可**跳過本章**。

統計字數：`npm run count:chars`

統計字數：

```bash
node scripts/count-story-chars.mjs
```
