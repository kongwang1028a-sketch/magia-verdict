# 魔女審判模擬 — 孤島監牢

類型致敬《魔法少女的魔女審判》的**原創短案**辯論小遊戲：蒐證 → 異議駁斥 → 指認魔女。

非原作劇情／角色，僅模擬「日常蒐證 + 審判辯論」節奏。

## 怎麼玩

1. **案情**：閱讀今夜的殺人案摘要  
2. **蒐證**：點選監牢各處，集齊 6 份證據  
3. **審判**：對每句證詞選出能指出矛盾的證據，按「異議！」  
4. **指認**：投票處刑你認定的魔女  

容錯 3 次；異議全錯或指認錯誤會進入 Bad End。正確答案藏在證詞與證據的對應裡。

## 本機執行

```bash
npm install
npm run dev
```

開發伺服器預設：`http://127.0.0.1:47321`

建置：

```bash
npm run build
npm run preview
```

## 技術

- Vite + React + TypeScript  
- Tailwind CSS v4  
- Framer Motion（轉場與微動效）

## 分支

遊戲開發請在 `develop` 分支進行；勿直接推 `main`。
