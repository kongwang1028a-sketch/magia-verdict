# 魔女審判模擬 — 孤島監牢

粉絲向《魔法少女的魔女審判》辯論小遊戲。使用原作角色名稱；劇情為粉絲向短案，非遊戲本篇。

## 文本切換

標題畫面可自由選擇文本：

| 文本 | 說明 |
|------|------|
| **無聲的鐘樓** | 現行重寫稿 |
| **祈禱堂的餘燼** | 封存舊稿，可回看 |

選擇會記在瀏覽器本地，並重置目前進度。

## 章節流程

1. 序章  
2. 日常  
3. 事件  
4. 搜索  
5. 審判辯論 → 指認  

右上角可**跳過本章**。容錯 3 次。指認需自行推理（介面不劇透兇手）。

## 本機執行

```bash
npm install
npm run dev
```

開發伺服器：`http://127.0.0.1:47321`

```bash
npm run build
npm run count:chars
```

## 技術

Vite + React + TypeScript + Tailwind CSS v4 + Framer Motion

## 分支

遊戲開發請在 `develop` 進行；勿直接推 `main`。
