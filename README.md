# 魔女審判模擬 — 孤島監牢

粉絲向《魔法少女的魔女審判》辯論小遊戲：蒐證 → 異議駁斥 → 指認魔女。

使用原作角色名稱與魔法設定；劇情為粉絲向原創短案，非遊戲本篇。

## 怎麼玩

1. **案情**：閱讀今夜的殺人案摘要  
2. **蒐證**：點選監牢各處，集齊 6 份證據  
3. **審判**：對每句證詞選出能指出矛盾的證據，按「異議！」  
4. **指認**：投票處刑你認定的魔女  

容錯 3 次；異議全錯或指認錯誤會進入 Bad End。正確答案藏在證詞與證據的對應裡（本短案兇手為紫藤亞里沙）。

## 本機執行

```bash
npm install
npm run dev
```

開發伺服器預設：`http://127.0.0.1:47321`

建置：

```bash
npm run build
npm run preview
```

## 技術

- Vite + React + TypeScript  
- Tailwind CSS v4  
- Framer Motion（轉場與微動效）

## 分支

遊戲開發請在 `develop` 分支進行；勿直接推 `main`。
